## Verified passes (2026-10-29)

- Keyboard: card Move button opens the Move dialog with focus inside it; arrow keys pick a column; Tab and Enter confirm; focus returns to the moved card. A real mouse drag and dispatched drag events move cards; there is no touch drag (HTML5 drag-and-drop does not fire on touch screens), so touch users move cards with the Move dialog. Logged as P-033.
- Mobile width (375 px): board, projects, project, activity, trash, people, inbox, my-tasks, settings and sign-in have no horizontal page overflow. The settings tab strip scrolls inside its own container.
- Dark theme: board, drawer, sign-in and projects checked; the other new screens use the same tokens but were not each inspected.
