**Why and options:** A cache is a saved copy used to avoid another request. Flowboard must track every copy that holds protected data: clearing the visible board query does not refresh the Projects hub or erase a separate module map. Retain the person's own unsent edits and original uncertain command, while erasing clean server baselines on refusal. A dialog stack similarly gives only the top dialog responsibility for Escape and focus. A fresh card form should begin only after the previous creation has a definite result, preserving retry safety.
