# Installed dependency repair — local evidence, not release approval

The original lock reported affected PostCSS and Undici via Next/Wrangler. The patched compatible choices were PostCSS8.5.23 and Wrangler4.156.2 (Miniflare5.20261102.0-beta, Undici7.30.1); Next remains15.5.28. The source advisory for the remaining PostCSS map-read issue identifies8.5.23 as patched: [GHSA-fxqj-rqcc-2cmp](https://github.com/advisories/GHSA-fxqj-rqcc-2cmp). The Undici redirect/cache advisory identifies7.30.1 as patched and describes its affected composition: [GHSA-4w7w-5xrc-9h26](https://github.com/advisories/GHSA-4w7w-5xrc-9h26). This does not assert that Flowboard exercised every vulnerable path before repair.

The initial npm11.12.1 package-lock-only update retained old nested PostCSS despite the root override. A clean temporary resolution produced the patched node. A candidate containing only that resolved PostCSS subtree was tested by `npm ci --ignore-scripts` in a manifest-only temp directory; install succeeded, but `npm ls` then detected that the workspace's Next edge did not inherit the override. Inspecting the installed npm Arborist graph confirmed an override on the workspace Link and none on its target. Declaring the already-used pinned Next build tool at the root lets the override reach its dependency; the final root install and `npm ls` both pass. No npm source or vendored dependency code was edited. The final lock keeps unrelated dependency pins.

Final local evidence: `raw/dependencies-final-install.log` exit0 (321 installed packages), `raw/dependency-tree-final.json` exit0 and selected installed versions verified from package manifests. Pinned Playwright1.64.1 is now a declared development tool for reproducible local/CI browser checks. The sanitized public-registry audit `raw/npm-audit-final-all.json` exits0 with0 critical/high/moderate/low/info advisories. Credentials were absent from the child process environment, user config was `/dev/null`, global config used a distinct empty path and registry was explicitly public npm. No account credentials/application data were sent.
