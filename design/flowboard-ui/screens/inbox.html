Inbox keys

Previewing a thread does not mark it read. Opening the card does.

J↓
Next thread
K↑
Previous thread
Enter
Open the selected card or target
E
Mark the selected thread read or unread
U
Jump to the next unread thread
/
Search notifications
Esc
Clear search, or return focus to the list

Shortcuts stay out of the way while you type, while a dialog is open, and when a modifier key is held.
