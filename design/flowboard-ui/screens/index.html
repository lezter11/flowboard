What this is not

Keep design evidence separate from implementation evidence.

No API or persistence. Reloading keeps this tab's demo edits; nothing is saved by the API. The theme preference persists.
No authorization. Role preview hides controls, but only the API can enforce project access.
No XLSX parsing or uploads. Import uses sample rows; no workbook bytes leave the browser.
No email delivery. Invitations are recorded locally and send nothing.

Run locally

A local server keeps clipboard and storage behavior consistent.

python3 -m http.server 4173 --bind 127.0.0.1 --directory design/flowboard-ui
