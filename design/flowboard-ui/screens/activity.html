Who sees what

Activity is scoped before it is filtered

Owner sees card history and access events across every owned project.

Manager sees card history and access events for granted projects only.

Member and Viewer see card history in granted projects. Access, trash, import and settings events stay hidden.

Filters never widen scope. They can only narrow the events the current role may already see.

About this feed

Read-only history

Activity records are append-only in the product. This prototype keeps them in memory and does not write an audit log.

Not an audit trail. A production owner-visible access log needs server-side retention, immutability and export rules that are not designed here.
Card links open the approved board artifact with the current role. Access-event links open project, trash or import screens where the role allows.
Activity · synthetic events · design evidence only No audit log, export or persistence is implemented.
