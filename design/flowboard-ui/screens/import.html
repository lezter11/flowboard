Atomic commit

No partial success

All rows valid means every nonempty row is ready.
One invalid or conflicting row blocks the entire batch.
Fixing rows means editing the workbook and uploading again. There is no partial retry.
No XLSX parsing here. This prototype shows sample rows. It does not read workbook bytes, validate real formulas or contact an API.

What does not import

Comments, mentions or activity history.
Images or image URLs.
Projects, boards, people, grants or roles.
Card keys. The server assigns those.
Unknown people or statuses block the batch. The importer never creates accounts or silently falls back to a default person.
Import · sample previews · design evidence only No XLSX parsing, upload, API or persistence is implemented.
